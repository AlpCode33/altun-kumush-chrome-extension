# ئالتۇن-كۈمۈش باھاسى

ئۇيغۇرچە، ئوڭدىن سولغا يېزىلىدىغان Chrome قىستۇرمىسى. ئالتۇن ۋە كۈمۈش باھاسىنى كۆرۈش، ئېغىرلىق ۋە ساپلىقنى ھېسابلاش، نىساب بويىچە زاكاتنى مۆلچەرلەش ئىقتىدارلىرى بار.

## ئىقتىدارلىرى

- ئالتۇن (XAU) ۋە كۈمۈش (XAG) نىڭ ئامېرىكا دوللىرىدىكى باھاسىنى تور مەنبەلىرىدىن يېڭىلاش
- باھا دىئاگراممىسى ۋە ئالتۇن/كۈمۈش ئالماشتۇرغۇچ
- گرام، تروي ئۇنسىيە، سەر ۋە مىسقال بويىچە ئېغىرلىق ھېسابلاش
- ئالتۇننىڭ 24K، 22K، 18K ۋە 14K ساپلىق دەرىجىسىنى ھېسابلاش
- ئالتۇن ۋە كۈمۈش نىسابى بويىچە زاكات ھېسابلىغۇچ
- باھا چەك نىشانى، قاراڭغۇ ۋە يورۇق كۆرۈنۈش

## Chrome غا ئورنىتىش

1. بۇ رېپونى چۈشۈرۈڭ ياكى كلونلاڭ:

   ```sh
   git clone https://github.com/AlpCode33/altun-kumush-chrome-extension.git
   ```

2. Chrome دا `chrome://extensions/` نى ئېچىڭ.
3. **Developer mode** نى قوزغىتىڭ.
4. **Load unpacked** نى بېسىپ رېپو قىسقۇچىنى تاللاڭ.

## مەخپىيەتلىك ۋە باھا مەنبەلىرى

قىستۇرما ئانالىز، ئېلان ياكى ئىز قوغلاش مۇلازىمىتىنى ئىشلەتمەيدۇ. باھانى يېڭىلاش ئۈچۈن `data-asg.goldprice.org` ۋە زاپاس مەنبە سۈپىتىدە `api.gold-api.com` غا تور ئۇلىنىشى ئەۋەتىدۇ. بۇ مۇلازىمەتلەر ئىشلەتكەندە IP ئادرېسىڭىزنى كۆرۈشى مۇمكىن. ساقلانغان باھا ۋە تەڭشەكلەر Chrome نىڭ يەرلىك ساقلىغۇچىسىدا ساقلىنىدۇ.

يېتەرلىك باھا ئۇچۇرىغا ئېرىشكىلى بولمىغاندا، قىستۇرما ئىچىدىكى ئۈلگىلىك قىممەتلەر كۆرسىتىلىشى مۇمكىن. پۇل ئايلاندۇرۇش نىسبەتلىرى كود ئىچىدىكى مۇقىم مۆلچەر قىممەتلىرى بولۇپ، نەق مەيدان پۇل نىسبىتى ئەمەس. ھېسابلاش نەتىجىسى مەبلەغ سېلىش ياكى دىنىي ھۆكۈمەت مەسلىھەتىنىڭ ئورنىنى ئالمايدۇ.

## تەرەققىي قىلدۇرۇش

قىستۇرما قوشۇمچە بوغچا ئورنىتىشنى تەلەپ قىلمايدۇ. JavaScript نى تەكشۈرۈش ئۈچۈن:

```sh
node --check popup.js
```

GitHub Actions ھەر قېتىم push ياكى pull request بولغاندا JavaScript گرامماتىكىسى ۋە Manifest JSON نى تەكشۈرىدۇ.
