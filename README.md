# ئالتۇن-كۈمۈش باھاسى

ئۇيغۇرچە (ئوڭدىن سولغا) كۆرۈنمە يۈزى بار Chrome Manifest V3 قىستۇرمىسى. ئالتۇن-كۈمۈشنىڭ باھاسىنى كۆرسىتىدۇ، ئېغىرلىق ۋە ئالتۇن ساپلىقىنى ھېسابلايدۇ، نىساب بويىچە زاكات سوممىسىنى مۆلچەرلەيدۇ.

## ئىقتىدارلىرى

- ئالتۇن (XAU) ۋە كۈمۈش (XAG) نىڭ ئامېرىكا دوللىرىدىكى باھاسىنى تور مەنبەلىرىدىن يېڭىلاش
- باھا دىئاگراممىسى، ئۆسۈش-چۈشۈش كۆرسەتكۈچى ۋە ئالتۇن/كۈمۈش تاللىشى
- گرام، تروي ئۇنسىيە، سەر ۋە مىسقال بويىچە ئېغىرلىق ئايلاندۇرۇش
- ئالتۇننىڭ 24K، 22K، 18K ۋە 14K ساپلىق دەرىجىسىنى ھېسابلاش
- ئالتۇن ۋە كۈمۈش نىسابى بويىچە زاكات ھېسابلىغۇچ
- باھا چەك نىشانى، قاراڭغۇ ۋە يورۇق كۆرۈنۈش

## Chrome غا ئورنىتىش

1. بۇ رېپونى چۈشۈرۈڭ ياكى كلونلاڭ:

   ```sh
   git clone https://github.com/AlpCode33/altun-kumush-chrome-extension.git
   ```

2. Chrome دا `chrome://extensions/` نى ئېچىڭ.
3. **Developer mode** نى قوزغىتىڭ.
4. **Load unpacked** نى بېسىپ رېپو قىسقۇچىنى تاللاڭ.

## مەخپىيەتلىك ۋە باھا مەنبەلىرى

قىستۇرما ئانالىز، ئېلان ياكى ئىز قوغلاش كودىنى ئۆز ئىچىگە ئالمايدۇ. نەق باھا يېڭىلاش ئۈچۈن `data-asg.goldprice.org` مۇلازىمىتىگە، زاپاس سۈپىتىدە `api.gold-api.com` مۇلازىمىتىگە تور تەلىپى ئەۋەتىلىدۇ. بۇ مۇلازىمەتلەر ئىشلەتكەندە IP ئادرېسىڭىزنى كۆرۈشى مۇمكىن. باھا ساقلاش ۋە تەڭشەك ئۈچۈن Chrome ساقلىغۇچىسى ئىشلىتىلىدۇ.

تور مەنبەسىدىن باھا ئېلىنالمىغاندا قىستۇرما ئىچىدىكى ئۈلگىلىك قىممەتلەر كۆرسىتىلىشى مۇمكىن. پۇل ئايلاندۇرۇش نىسبەتلىرى كود ئىچىدىكى مۇقىم مۆلچەرلەر بولۇپ، نەق مەيدان پۇل نىسبىتى ئەمەس. دىئاگرامما تارىخى ۋە بازار كەيپىياتى كۆرسەتكۈچى نەق مەيدان تارىخىي سانلىق مەلۇمات ياكى مالىيە مەسلىھەتى ئەمەس. باھا ۋە زاكات ھېسابلاش نەتىجىلىرى پەقەت مۆلچەر بولۇپ، مالىيە ياكى دىنىي ھۆكۈم مەسلىھەتىنىڭ ئورنىنى ئالمايدۇ.

## تەكشۈرۈش

قوشۇمچە بوغچا ئورنىتىش تەلەپ قىلىنمايدۇ. JavaScript گرامماتىكىسىنى تەكشۈرۈش:

```sh
node --check popup.js
```

GitHub Actions ھەر قېتىم push ياكى pull request تا JavaScript گرامماتىكىسى، Manifest JSON ۋە ئۇنىڭدا كۆرسىتىلگەن ھۆججەتلەرنى تەكشۈرىدۇ.
